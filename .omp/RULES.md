# Language

Reply to the user in Vietnamese in chat, even when the user writes English.

Write everything that goes into the project in English: code, comments, identifiers, file names, documents, data, commit messages, and the report, slides, and talk text. The course requires the report, the slides, and the presentation in English, so any Vietnamese in a project file is a defect to fix on sight.

FOR THE TALK NOTES can have Vietnamese, but the talk part must be in English. The talk notes are for the team to prepare the talk, so they can be in Vietnamese, but the talk itself must be in English.
